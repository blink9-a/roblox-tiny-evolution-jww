# roblox-tiny-evolution-jww

## 프로젝트 소개 (Project Overview)

**Tiny Evolution**은 Roblox Studio로 제작하는 탐험·생존 게임입니다.

플레이어는 작은 생물이 되어 섬을 탐험하며 먹이를 찾고, 포식자를 피하고, 알을 보호하는 3가지 미션을 수행합니다.

각 미션을 통해 동물이 자연에서 살아남고 번식하는 과정을 체험하며, 생존과 관련된 기초 생물학 개념을 배우는 것을 목표로 합니다.

## 실행 방법 (How to Run)

1. GitHub에서 `.rbxl` 파일을 다운로드합니다.
2. Roblox Studio를 실행합니다.
3. 다운로드한 `.rbxl` 파일을 Roblox Studio에서 엽니다.
4. 상단의 **Play** 버튼을 눌러 게임을 실행합니다.
5. **WASD** 키로 캐릭터를 이동합니다.
